# Contributing to a FacMed Hack challenge

1. Work on a branch, never directly on `main`.
2. Merge through a pull request, and say in it how you checked what changed.
3. Log each pull request in `NOTES.md`: what the AI changed, how you checked it, what you trusted.
4. Never commit data, keys or participant-level outputs. `data/sources.yaml` says where data lives.
5. Coding agents follow the repository's `AGENTS.md`.

Questions go in an issue (**Question** template) or to your challenge runner.
